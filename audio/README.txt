SUARA PESANAN MASUK
===================
Aplikasi memutar nada lonceng (pesanan-masuk-chime.mp3), lalu mengucapkan
"Ada pesanan masuk" dengan suara Bahasa Indonesia bawaan perangkat.

Ingin memakai REKAMAN SUARA SENDIRI?
  1. Rekam kalimat "Ada pesanan masuk" (maks. ±3 detik, format MP3).
  2. Simpan di folder ini dengan nama persis:  ada-pesanan-masuk.mp3
  3. Upload ulang ke GitHub (git add . && git commit && git push).
Jika berkas itu ada, otomatis dipakai menggantikan suara mesin (lebih konsisten di semua HP/PC).
